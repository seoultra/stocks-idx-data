# IDX stock fundamentals — raw JSON

Source-backed fundamentals and daily prices for companies listed on the Indonesia Stock
Exchange (IDX), published as plain JSON files you can fetch like an API. This repository is
the data behind [seoultra.id/stocks/idx](https://seoultra.id/stocks/idx/). The first release
covers the four largest Indonesian banks.

Every number records the document it was read from, the type of source, its as-of date and
the page or table. A figure that the company did not disclose is `null`. Nothing is
estimated, interpolated or filled in.

*Data fundamental saham BEI dalam format JSON. Setiap angka mencantumkan dokumen sumber,
tanggal dan halamannya. Bukan rekomendasi investasi.*

Each issuer file holds annual data from FY2020 (FY2019 balance-sheet levels only, for
averages and growth), every dividend paid out of those years, and the latest interim
period (Q1, H1 or 9M) with the same period a year earlier.

Each price file holds the daily open, high, low, close and volume of every trading session
since 2 January 2019. It is updated twice every trading day (Monday to Friday, WIB):

- **About 09:20:** today's opening price is published as `today` (marked provisional).
- **About 17:30:** today's full row (open, high, low, close, volume) is added to `rows`
  and `today` is removed.

This is not a real-time feed.

## Fetching the data

No key or sign-up. Every file is served over HTTPS with `Access-Control-Allow-Origin: *`,
so a browser page can fetch it directly.

| What | URL |
|---|---|
| Index (start here) | https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/index.json |
| One issuer | https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/issuers/BBCA.json |
| Daily prices of one issuer | https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/prices/BBCA.json |
| Sectors | https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/sectors.json |
| Corporate actions | https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/corporate_actions.json |
| BI-Rate and 10Y SBN | https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/macro.json |
| Validation report | https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/validation_report.json |

The same files are on the jsDelivr CDN, e.g.
`https://cdn.jsdelivr.net/gh/seoultra/stocks-idx-data@main/index.json`. The CDN can lag
`main` by several hours. To make a result reproducible, replace `main` with a commit SHA in
either URL.

```sh
# BBCA FY2025 net profit attributable to owners, with its source
curl -s https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/issuers/BBCA.json \
  | jq '.fy["2025"].net_profit_attr | {v, source_url, loc}'
```

```sh
# Today's opening price, while the session is running (null outside trading hours)
curl -s https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/prices/BBCA.json | jq '.today'

# BBCA's last five sessions: date, open, high, low, close, volume
curl -s https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/prices/BBCA.json \
  | jq -c '.rows[-5:][]'
```

```js
const base = 'https://raw.githubusercontent.com/seoultra/stocks-idx-data/main/';
const index = await (await fetch(base + 'index.json')).json();
const bbca = await (await fetch(base + index.issuers.find(i => i.code === 'BBCA').file)).json();
console.log(bbca.fy['2025'].net_profit_attr.v); // IDR billion

// Daily closes on today's share basis (prices are stored as traded; undo splits, bonus and
// rights issues like this)
const px = await (await fetch(base + 'prices/BBCA.json')).json();
const rights = (px.source.reversed || []).filter(r => r.type === 'rights');
const factor = d => px.splits.filter(s => s.ex_date > d).reduce((f, s) => f * s.factor, 1)
                  / rights.filter(r => r.ex_date > d).reduce((k, r) => k * r.yahoo_factor, 1);
const closes = px.rows.map(([d, o, h, l, c]) => [d, c / factor(d)]);
```

## What a number looks like

Every value is a *datum*:

```json
{
  "v": 57537.287,
  "source_url": "https://www.bca.co.id/-/media/Feature/Report/File/S8/Laporan-Diaudit/2026/20260127-audited-financial-statement-bca-31-december-2025-english-combined.pdf",
  "source_type": "filing",
  "as_of_date": "2025-12-31",
  "loc": "PDF p. 10, Consolidated Statement of Profit or Loss - Net income attributable to equity holders of parent entity",
  "basis": "consolidated",
  "note": "Audited FY2025 consolidated FS, Rp juta / 1,000."
}
```

`source_type` is `filing` (financial statements and annual reports), `company_release`
(the issuer's own press releases, presentations and disclosures), `official` (e.g. Bank
Indonesia) or `news` (cross-check only). The full field list is in [SCHEMA.md](SCHEMA.md).

## Read this before using the numbers

- **Units.** Money is in IDR **billion**. Per-share values are in rupiah. Ratios are in
  percent (`23.9` means 23.9%). Dates are `YYYY-MM-DD`.
- **Daily prices are stored as traded.** Each price file lists its own `splits`. Divide
  prices before each `ex_date` by its `factor` to get a continuous series (the JavaScript
  example above does this). They are not adjusted for dividends.
- **Daily prices come from Yahoo Finance** and are checked before every commit: each price
  must be a valid IDX tick, no close may move more than 35% in a session, and the last
  close of every year must match the year-end price printed in the annual report.
  Yahoo's own split and rights-issue scaling is reversed; see `source` in each file.
- **Per-share values are stored as printed, not split-adjusted.** Each one carries a
  `share_basis` date. To put it on today's share count, divide by
  `ratio_new / ratio_old` for every split in `corporate_actions.json` whose `ex_date` is
  after that date (and multiply share counts by the same factor). Example: BCA paid Rp98 +
  Rp432 = Rp530 per share out of FY2020 profit. Its 1:5 split went ex on 2021-10-13, so
  that is Rp106 per share today. Rights issues are listed but do not change the factor.
- **Consolidated and bank-only figures are never mixed.** Profit, EPS, equity, assets,
  loans and deposits are consolidated. Ratios are stored exactly as the bank reports them,
  and `basis` says which basis that is.
- **Dividend `fy` is the year of the profit**, not the year of payment. An interim
  dividend paid in December 2025 and the final paid in April 2026 are both `fy: 2025`.
- **Derived values are not stored.** Growth, CAGR, book value per share, ROE on average
  equity and the scorecard are computed by the website. The formulas are on the
  [methodology page](https://seoultra.id/stocks/methodology/).

## How the data is checked

A change is validated before it is committed, and the website validates every commit
again before it switches to it. A commit that fails is never shown on the site.

- **Schema:** every number needs an https source, a valid date and the right unit and
  basis, and ratios must sit inside a plausible range.
- **Cross-checks** must agree within 3%: profit × payout ≈ total dividend,
  DPS × shares ≈ total dividend, and EPS × shares ≈ profit.
- A gap with a real cause is explained, never edited away. It goes in the issuer's
  `validation_ack` with the reason. For example, BBRI's 2021 rights issue makes its
  reported EPS use weighted-average shares.

The result for every issuer is in [validation_report.json](validation_report.json).

## Updates and corrections

Annual figures are added after each annual report, usually in March or April. Interim
figures follow the Q1, H1 and 9M results. Daily prices are committed twice per trading day
(opening price, then the full row after the close). The commit history is the changelog.

If you find a wrong number, please open an issue with the document and page that show
the correct figure.
