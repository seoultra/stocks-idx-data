# IDX stocks: open JSON data

Fundamentals and daily prices for the **banks, energy companies and consumer staples companies listed
on the Indonesia Stock Exchange (IDX)**, as plain JSON files you can fetch like an API. Every number links
to the document and page it came from. This is the data behind [seoultra.id/stocks/idx](https://seoultra.id/stocks/idx/)
(banks), [/energi](https://seoultra.id/stocks/idx/energi/) (energy) and [/konsumen](https://seoultra.id/stocks/idx/konsumen/) (consumer staples).

*Data saham bank, energi dan barang konsumen primer BEI dalam JSON. Setiap angka bersumber. Bukan rekomendasi investasi.*

| What | Coverage |
|---|---|
| Fundamentals | FY2020–FY2025 plus the latest quarter, from annual reports and financial statements |
| Dividends and corporate actions | Every cash dividend, split, bonus issue and rights issue since 2019 |
| Daily prices | Open, high, low, close and volume since 2019, updated every trading day (open ~09:20, close ~17:30 WIB) |
| Checks | Every commit is validated before it is published ([validation_report.json](validation_report.json)) |

## Quick start

No key, no sign-up. Files are served with CORS, so a web page can fetch them directly.

```sh
BASE=https://raw.githubusercontent.com/seoultra/stocks-idx-data/main
curl -s $BASE/index.json         | jq -c '.issuers[] | {code, group, file}'
curl -s $BASE/issuers/BBCA.json  | jq '.fy["2025"].net_profit_attr | {v, source_url, loc}'
curl -s $BASE/prices/BBCA.json   | jq -c '.rows[-5:][]'   # [date, open, high, low, close, volume]
```

| File | Holds |
|---|---|
| [index.json](index.json) | Start here: every issuer, its sector, group, currency, periods and file paths |
| `issuers/<CODE>.json` | Annual and latest-quarter figures, dividends, research notes |
| `prices/<CODE>.json` | Daily prices, stored as traded |
| [sectors.json](sectors.json) | The sectors (banking, energy, consumer) and their display groups |
| [corporate_actions.json](corporate_actions.json) | Splits, bonus issues and rights issues |
| [macro.json](macro.json) | BI-Rate and the 10-year SBN yield |
| [SCHEMA.md](SCHEMA.md) | Every field, unit and rule in detail |

The same files are on jsDelivr (`https://cdn.jsdelivr.net/gh/seoultra/stocks-idx-data@main/…`),
which can lag by a few hours. Use a commit SHA instead of `main` for reproducible results.

## Good to know

- **Units.** Money in IDR billion, or **USD million** for companies that report in dollars
  (`currency` in each issuer file; never converted). Per-share values and prices in rupiah, ratios
  in percent (`23.9` = 23.9%), dates `YYYY-MM-DD`.
- **Every number is a datum**: `{v, source_url, source_type, as_of_date, loc, basis}`. A figure the
  company did not disclose is `v: null` with a note. Nothing is estimated or filled in.
- **Prices and per-share values are stored as traded.** For a continuous series, divide each row by
  the `splits` factors (splits and bonus issues) dated after it, and multiply by the rights factors
  in `source.reversed`:

  ```js
  const px = await (await fetch(BASE + '/prices/BBCA.json')).json();
  const rights = (px.source.reversed || []).filter(r => r.type === 'rights');
  const f = d => px.splits.filter(s => s.ex_date > d).reduce((a, s) => a * s.factor, 1)
              / rights.filter(r => r.ex_date > d).reduce((a, r) => a * r.yahoo_factor, 1);
  const closes = px.rows.map(([d, , , , c]) => [d, c / f(d)]);
  ```

- **Consolidated and bank-only figures are never mixed**; `basis` says which. Sharia banks report
  NPF and FDR in place of NPL and LDR (`label_overrides`).
- **Dividend `fy` is the year of the profit**, not the year it was paid.
- **Derived values are not stored** (growth, CAGR, ROE on average equity, scores). The formulas are
  on the [methodology page](https://seoultra.id/stocks/methodology/).
- **Source conflicts are documented, never edited away**: see `validation_ack` and
  `research_notes` in each issuer file (for example, an annual report whose year-end price differs
  from the last traded close).

## Corrections and disclaimer

Found a wrong number? Open an issue with the document and page that show the right one. The commit
history is the changelog.

**Not investment advice** (*bukan rekomendasi investasi*). The data is compiled from public company
documents and may contain errors. Check the linked source before you rely on a figure.
